# n8n workflows

JSON bodies for the n8n public API, generated by the `build-*.js` scripts next to them.

| Workflow | n8n ID | Status |
|---|---|---|
| `MTR – 99 Error Handler` | `CS7g4VWEMmGhn3DQ` | Created, inactive (error workflows run without being active) |

## Conventions for every MTR workflow

- Settings → **Error workflow** = `MTR – 99 Error Handler`.
- When a Code node throws on purpose, start the message with `deal <id>:` (e.g. `deal 123456789: CCEW note not found`). MTR – 99 turns that into a HubSpot link in the alert and the subject.
